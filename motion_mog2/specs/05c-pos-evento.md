Objetivo: pós-evento configurável em segundos; movimento que volta durante o pós-evento continua no mesmo MP4; MP4 só fecha imediatamente antes de um keyframe, para a fila recomeçar em keyframe sem descartar pacotes.
1) Config: struct EventRecordingConfig { std::string input_source; std::filesystem::path output_directory; double pre_event_seconds=5; double post_event_seconds=5; double motion_threshold_percent=1.0; int motion_start_frame_count=2; int motion_end_frame_count=3; }. Função EventRecordingConfig parseEventRecordingArguments(int argument_count, char** argument_values) com a CLI: [fonte] [diretorio_saida] [pre_evento_s] [limiar_%] [inicio_frames] [fim_frames] [pos_evento_s] (pos_evento_s é o 7º, padrão 5). Mover para ela todo o parsing hoje no main (mesmas regras e mensagens). pos_evento_s: mesmas regras de pre_evento_s (finito, >= 0), mensagem citando pos_evento_s. Limiar: qualquer texto não numérico ou consumo parcial => std::invalid_argument("Limiar de movimento invalido: <texto>") (hoje "abc" vaza a mensagem do std::stod). Erros => std::invalid_argument. --help/-h e > 8 argumentos continuam no main; atualizar o texto de uso (remover a frase sobre alvo de pacotes).
2) EncodedPacketQueue: novo método std::vector<AvPacketPtr> takeCountedPacketsBeforeNextKeyframe(bool& keyframe_found). Move da frente da região contabilizada enquanto o pacote da frente não for keyframe (inclusive a posição 0); para no primeiro keyframe sem retirá-lo. keyframe_found = true se parou num keyframe contabilizado; false se esvaziou a região sem achar. Região à frente intocada. Mesmo lock único dos outros métodos.
3) main: post_event_packet_count = calculatePreEventFrameCount(post_event_seconds, fps) (1 pacote = 1 frame). Logar POST_EVENT seconds=... packets=... junto do PRE_EVENT. Trocar event_active/waiting_for_keyframe por enum class RecordingState { idle, waiting_keyframe, recording, post_event, closing_at_keyframe }. Por read, após advance(N) e detectMotion, conforme o estado:
- idle: se started => log EVENT_STARTED; lote = takeCountedPacketsFromLookback(lookback); vazio => waiting_keyframe (log EVENT_WAITING_KEYFRAME); senão abrir MP4, escrever, log PRE_EVENT_WRITTEN packets=<n>, => recording. Sem started => trimCountedPackets(lookback, maximum_idle).
- waiting_keyframe: discardCountedPacketsBeforeFirstKeyframe(); lote = takeCountedPackets(); não vazio => abrir MP4, escrever, => recording (e, se ended neste mesmo frame, aplicar a transição de ended abaixo). Vazio e ended => log EVENT_DISCARDED_NO_KEYFRAME, => idle.
- recording: escrever takeCountedPackets(). Se ended => log EVENT_ENDED frame=<i>; post_remaining = post_event_packet_count; se post_remaining == 0 => closing_at_keyframe, senão => post_event.
- post_event: se started => log EVENT_RESUMED frame=<i>, escrever takeCountedPackets(), => recording. Senão: lote = takeCountedPackets(); escrever; post_remaining -= min(post_remaining, lote.size()); se post_remaining == 0 => log POST_EVENT_EXPIRED frame=<i>, => closing_at_keyframe.
- closing_at_keyframe: se started => log EVENT_RESUMED, escrever takeCountedPackets(), => recording. Senão: lote = takeCountedPacketsBeforeNextKeyframe(found); escrever lote se não vazio; se found => finalizar MP4 (MP4_SAVED), => idle.
Após o laço (provisório até a spec 06): se houver MP4 aberto, escrever takeCountedPackets() e finalizar.
Escrita sempre fora do lock; verificação de keyframe no 1º lote do arquivo mantida.
